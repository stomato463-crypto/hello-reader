# サポートシステムの構築 (Nadeshiko v3 仕様書)

## 1. サポートタブの追加
`app\src\main\java\com\stomato\helloreader\MainActivity.kt` に、4番目のタブを追加。
* タブ名: 「サポート」
* アイコン: 🆘
* Jetpack Compose コンポーネントを使用。

## 2. 画面レイアウトと案内
* 見出し: 「🆘 サポート・お問い合わせ」 (heading 属性付与)
* 案内文: 「問い合わせ・ご意見は下記のボタンを押して表示されるメール作成画面の本文に入力して送信してください。」

## 3. メーラー起動とメール内容
* メールの件名: 「■hello-reader問い合わせ・ご意見」
* メールの宛先: Base64 難読化されたサポート用メールアドレス
* 本文内容: 端末情報 (OS, 機種, ビルド), b3sum 匿名識別ハッシュ, 設定状態, 直近動作ログ (最新20件)

## 4. 条件分岐とエラーハンドリング (もし〜違えば)
* もし、複数のメーラーがインストールされていれば、OS標準のメーラー選択画面 (Chooser) を表示。
* 違えば、標準メーラーを直接起動。
* もし、メーラーの起動に失敗したならば、
  「メーラーの起動に失敗しました。診断ログをクリップボードにコピーしました」と表示し、
  クリップボードに診断ログを自動コピー。
